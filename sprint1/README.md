# Kampüs Etkinlikleri - Sprint 1

Bu proje, mühendislik ve kampüs etkinliklerini listeleyen, saf semantik HTML ile hazırlanmış bir web uygulaması iskeletidir. CSS ve JavaScript içermez.

## Sayfa Yapısı
- `index.html`: Uygulama tanıtımı ve yaklaşan iki öne çıkan etkinlik.
- `etkinlikler.html`: Tek sütunlu çerçeveli tablo formatında etkinlik listesi ve aylık özet takvim.
- `etkinlik-detay.html`: TEDx konferansı afişi, künye tanım listesi ve ayrıntılı açıklama.
- `detay-biyomedikal.html`: Biyomedikal sinyal işleme çalıştayı detay sayfası.
- `detay-radar.html`: Radar ve otonom sistemler semineri detay sayfası.
- `detay-fpga.html`: FPGA donanım hackathonu detay sayfası.
- `detay-yapayzeka.html`: Yapay zeka ve etik paneli detay sayfası.
- `etkinlik-ekle.html`: Semantik form etiketleriyle yeni etkinlik oluşturma arayüzü.
- `etkinlik-guncelle.html`: Seçim menüsü ve varsayılan değerlerle hazırlanmış düzenleme arayüzü.
