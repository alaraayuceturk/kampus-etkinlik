# Kampüs Etkinlik Yönetim Sistemi (Sprint 6 & Vize Projesi)

## 🌐 Canlı Vercel Adresi
* [Proje Canlı Linki](https://alarayuceturk-frontend.vercel.app/)

## 🚀 Kurulum ve Çalıştırma
Projeyi yerel ortamınızda çalıştırmak için sırasıyla şu komutları kullanabilirsiniz:
\`\`\`bash
npm install
npm run dev
\`\`\`

## 🗺️ Route (Sayfa) Listesi
1. Ana Sayfa (`/`)
2. Etkinlikler (`/events`)
3. Etkinlik Detay (`/events/:id`)
4. Admin Paneli (`/admin`)
5. Etkinlik Ekle (`/admin/add`)
6. Etkinlik Düzenle (`/admin/edit/:id`)
7. Giriş Yap (`/login`)
8. Kayıt Ol (`/register`)
9. Şifremi Unuttum (`/forgot-password`)
10. Sayfa Bulunamadı (`*` / 404)
